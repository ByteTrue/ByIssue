# 导出记录顺序

## 结论

导出记录保留上游原始顺序，导出阶段不按名称或其他字段重新排序。

这条约束只覆盖导出阶段。上游给什么顺序，导出就输出什么顺序；下游对账用的序号就是上游序号。

代码和配置不能说明这条约束为什么存在，所以单独记录在这里。

## 依据

- 类型：用户决定
- 证据或复核方式：用户确认已签署的合作协议按上游原始序号对账。导出重排会让协议上的序号与导出行不一致。复核方式是检查导出入口在写文件前是否对记录重新排序。
- 影响结论适用性的观察条件、版本或环境：结论以现有合作协议为前提，与实现语言、存储格式和部署环境无关。

## 重访条件

合作协议重新签署时重新讨论这条决定。除此之外，导出相关的新需求（排序、筛选、列顺序）都不能改变这一条。
