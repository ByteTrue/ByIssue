# 导出记录顺序

## 结论

导出记录必须保留上游原始顺序，导出阶段不能按名称重新排序。这条约束适用于所有导出记录的工作，包括以后新增的导出字段、筛选条件和批次处理。

已签署的合作协议使用上游原始序号对账，重排后双方无法按同一序号核对。这是当前唯一确认的依据。

## 依据

- 类型：用户决定
- 证据或复核方式：用户确认；核对时查看合作协议中的序号与导出记录的对应关系
- 影响结论适用性的观察条件、版本或环境：依据是当前已签署的合作协议，与合作方和协议版本绑定

## 重访条件

只有合作协议重新签署时，才重新讨论这条决定。协议内容或对账方式变化、合作方要求变化，都先回到用户确认，不能由实现侧自行调整顺序。
