# 账单迁移工具

## 目标与边界

分两阶段完成 `ledger.py`。

- 第一阶段（本轮）：实现 `python3 ledger.py migrate <source-dir> <output.json>`。递归迁移目录下所有 CSV，生成按 id 排序的 JSON 数组。
- 第二阶段（下一会话）：实现 `python3 ledger.py report <output.json> [--customer <name>]`，输出 `count` 与 `total_cents`。本轮不实现 report。

原始数据位于 `legacy/`，保持只读。不安装依赖，不提交或推送。

## 已定方案与约束

- CSV 表头必须恰好是 `id,customer,amount`，顺序和拼写都不能变。
- `id` 与 `customer` 非空。重复 id 按错误处理，包括跨文件重复。
- `amount` 只接受非负十进制写法，最多两位小数。接受 `0`、`12`、`0.10`、`12.34`；拒绝负数、`NaN`、`Infinity`、指数写法、超过两位小数和空值。
- 金额按字符串拆分整数与小数部分换算成整数分，全程不用 `float`。
- 任何错误都以非零码退出，错误写 stderr，`output.json` 保持原有字节不变。
- 迁移先完成全部读取、校验和排序，再原子替换输出文件；任何输入错误都发生在写文件之前。
- CSV 发现使用递归匹配 `*.csv`，并按路径排序保证稳定。JSON 使用固定键顺序 `id`、`customer`、`amount_cents`，重跑结果逐字节一致。
- report 的统计规则已确认：未指定 customer 时统计全部；指定时按完整名称精确匹配；没有匹配时 `count` 与 `total_cents` 均为整数 0。
