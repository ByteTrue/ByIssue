# 账单迁移工具

## 目标与边界

完整目标是 `ledger.py` 提供两个 CLI，本轮只实现第一个。

`python3 ledger.py migrate <source-dir> <output.json>`：

- 递归查找 source-dir 下所有 CSV，包括子目录。
- CSV 表头固定为 `id,customer,amount`。
- 输出 JSON 顶层是数组，按 id 排序，每行只有 `id`、`customer`、`amount_cents` 三个键。
- amount 是非负十进制金额，接受 `0`、`12`、`0.10`、`12.34` 这类普通写法，最多两位小数。拒绝负数、`NaN`、`Infinity`、指数格式和多于两位小数。金额换算必须精确，不使用浮点数。
- id 与 customer 不能为空。重复 id、错误表头或任一非法行都以非零码退出，错误写 stderr。
- 失败时原有 output.json 保持逐字节不变。
- 同一批输入重跑得到相同结果，原始 CSV 不变。

`python3 ledger.py report <output.json> [--customer <name>]`（下一次会话实现）：

- 输出 JSON 对象，只有 `count` 和 `total_cents` 两个整数。
- 未指定 customer 时统计全部；指定时按完整名称精确匹配。
- 没有匹配时两项均为 0。

## 已定方案与约束

- 实现放在项目根的 `ledger.py`，回归检查放在 `tests/test_ledger.py`，只用 unittest 和标准库。
- 金额用正则校验后按字符串拆整数部分和小数部分计算分，避免二进制浮点误差。
- 先完成全部读取与校验，再写同目录临时文件并用 `os.replace` 替换目标；任何错误发生在替换之前，因此旧输出不被改动。
- 本轮 `report` 明确返回非零码并在 stderr 说明尚未实现，不装作可用。
- 原始数据是 `legacy/` 下的 3 个 CSV、7 行数据；逐项覆盖记录在 `scope.md`。
