# 账单迁移工具 ledger.py

## 目标与边界

用户要一个只用 Python 3 标准库的命令行工具，分两次会话完成：

1. `ledger.py migrate <source-dir> <output.json>`：递归读取 source-dir 下所有 CSV，输出按 id 排序的 JSON 数组，每行只含 `id`、`customer`、`amount_cents`。
2. `ledger.py report <output.json> [--customer <name>]`：输出只含 `count` 和 `total_cents` 的 JSON 对象。不指定 customer 时统计全部；指定时按完整名称精确匹配；没有匹配时两项都为 0。

本轮已完成 migrate：实现、回归检查、在 `legacy/` 上真实运行。report 未实现、未测试，是下一次会话的唯一入口。原始数据 `legacy/` 只读，未改动。

## 已定方案与约束

- 表头必须逐字等于 `id,customer,amount`，否则整批失败。
- 金额只接受非负十进制、最多两位小数（如 `0`、`12`、`0.10`、`12.34`；也接受 `0.1` 与 `00.10`）。负数、`NaN`、`Infinity`、指数写法、超过两位小数、前后空白一律非法。用十进制字符串切分转整数分，不经过 float。
- `id` 和 `customer` 去空白后为空即非法；非空值原样保留，不做改名或裁剪。
- 重复 id、错误表头、任一非法行都以退出码 1 失败，错误写 stderr。
- 先完整解析并校验，全部通过后再原子写入输出文件（同目录临时文件 + `os.replace`），因此失败时已有 output.json 逐字节不变，也不创建新文件。
- 同一批输入重跑得到相同字节输出；CSV 只读，不被改动。
- 没有 CSV 的目录视为合法，输出 `[]`。输出父目录不存在时自动创建。
- 文件编码按 UTF-8（兼容 BOM）读取，CSV 按标准库 `csv` 解析，CRLF 和带引号逗号不影响结果。
- id 排序为字典序（`"10" < "2" < "a" < "b"`）。
- report 下一次会话再定实现，规则已写在「目标与边界」。
