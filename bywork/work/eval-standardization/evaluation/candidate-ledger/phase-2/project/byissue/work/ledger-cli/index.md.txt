# 账单迁移工具 ledger.py

## 目标与边界

用户要一个只用 Python 3 标准库的命令行工具，分两次会话完成：

1. `ledger.py migrate <source-dir> <output.json>`：递归读取 source-dir 下所有 CSV，输出按 id 排序的 JSON 数组，每行只含 `id`、`customer`、`amount_cents`。
2. `ledger.py report <output.json> [--customer <name>] [--min-cents <n>]`：输出只含 `count` 和 `total_cents` 的 JSON 对象。不指定 customer 时统计全部；指定时按完整名称精确匹配；没有匹配时两项都为 0。`--min-cents` 只统计 `amount_cents` 大于等于阈值的记录，默认 0，可与 `--customer` 同时使用；负数和非整数参数报错并非零退出。

migrate 已在此前会话完成：实现、回归检查、在 `legacy/` 上真实运行。本轮实现 report。原始数据 `legacy/` 只读，不因本轮改动。

## 已定方案与约束

- 表头必须逐字等于 `id,customer,amount`，否则整批失败。
- 金额只接受非负十进制、最多两位小数（如 `0`、`12`、`0.10`、`12.34`；也接受 `0.1` 与 `00.10`）。负数、`NaN`、`Infinity`、指数写法、超过两位小数、前后空白一律非法。用十进制字符串切分转整数分，不经过 float。
- `id` 和 `customer` 去空白后为空即非法；非空值原样保留，不做改名或裁剪。
- 重复 id、错误表头、任一非法行都以退出码 1 失败，错误写 stderr。
- 先完整解析并校验，全部通过后再原子写入输出文件（同目录临时文件 + `os.replace`），因此失败时已有 output.json 逐字节不变，也不创建新文件。
- 同一批输入重跑得到相同字节输出；CSV 只读，不被改动。
- 没有 CSV 的目录视为合法，输出 `[]`。输出父目录不存在时自动创建。
- 文件编码按 UTF-8（兼容 BOM）读取，CSV 按标准库 `csv` 解析，CRLF 和带引号逗号不影响结果。
- id 排序为字典序（`"10" < "2" < "a" < "b"`）。
- report 读取 migrate 产出的 JSON 数组，只读输入。默认阈值 0，过滤条件为 `amount_cents >= min_cents`，边界值包含在内。
- `--min-cents` 只接受由 ASCII 数字组成的非负整数，默认 0；负数、小数、空串和其他非整数写法由参数解析直接拒绝，退出码 2，错误写 stderr。
- report 的客户过滤使用完整名称精确匹配，不做大小写折叠或去空白。输出对象只含 `count` 和 `total_cents`。

## 证据与决定

- 回归检查位于 `tests/test_ledger.py`，共 23 个用例，从真实 CLI 以子进程驱动。重跑命令：`python3 -m unittest discover -s tests -v`。本轮结果：`Ran 23 tests ... OK`。
- 本轮真实入口在 `legacy/` 上先 migrate 到 `$TMPDIR/ledger-report.*/ledger.json`，再对同一文件运行 report。7 条记录、总额 101570 分；Alice 3 条 135 分；阈值 20 与 21 的差异证明 20 分记录计入下界；组合过滤得到 2 条 125 分。
- 非法 `--min-cents` 逐个真实运行，`-1`、`-0`、`abc`、`1.5`、`3.0`、`+1`、` 5`、空串全部退出码 2，stderr 报 `invalid non-negative integer`，stdout 为空。
- 检查有效性用临时副本故意做坏，三组变异都让对应用例失败：
  - 阈值 `>=` 改成 `>`：report 4 个用例失败，覆盖边界和默认值。
  - 去掉严格整数校验、直接 `int(text)`：非法阈值用例 8 个子用例失败，因为 `+1`、带空格等会被接受。
  - 去掉 customer 过滤条件：2 个用例失败。
- report 读取 JSON 后先校验数组、记录对象、customer 字符串和 amount_cents 整数，再统计。输入文件只读，不写临时文件。
- 实现只在 `ledger.py` 和 `tests/test_ledger.py`；`legacy/` 未改动。
- 范围覆盖见 `scope.md`，本轮重跑 `find legacy -type f -name '*.csv' | sort` 仍为三个文件，范围未变。
