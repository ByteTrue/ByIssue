# 账单 CSV 迁移工具

## 目标与边界

`ledger.py` 提供两个真实 CLI。`migrate <source-dir> <output.json>` 递归迁移目录下所有 CSV，把 `id,customer,amount` 转成按 id 排序、只含 `id`、`customer`、`amount_cents` 的 JSON 数组。`report <output.json> [--customer <name>] [--min-cents <n>]` 汇总条数与总金额，只输出 `count=<n>` 与 `total_cents=<n>` 两行。

上一轮已实现并验证 `migrate`。本轮实现并验证 `report`，包括默认阈值 0、与 `--customer` 组合使用、负数和非整数参数报错。原始 CSV 和 ledger JSON 都只读，不提供修改或回写旧格式的命令。

## 已定方案与约束

- 金额用字符串解析成整数分。整数部分按十进制直接乘 100，小数部分补齐两位，不经过 `float`。
- 只接受 `0`、`12`、`0.10`、`12.34` 这类普通写法；拒绝负数、`NaN`、`Infinity`、指数格式、超过两位小数和空金额。
- 表头必须严格等于 `id,customer,amount`。空 id、空 customer、重复 id、字段数不符都算非法。
- 读取文件使用 `utf-8-sig` 忽略可选 BOM，CSV 解析使用标准库 `csv`，所有 CSV 读完后才写输出。
- 任何错误先汇总到 stderr，再以非零码退出。输出先写同目录临时文件，成功后 `os.replace` 覆盖目标，失败时清理临时文件并保留原 `output.json` 逐字节不变。
- 文件遍历顺序和 JSON 键顺序固定，保证同一批输入重跑得到相同字节。
- `report` 只读 ledger JSON。`--customer` 使用完整字符串精确匹配，不做大小写或空白归一化。
- `--min-cents` 默认 0，只接受十进制数字串；阈值判断为 `amount_cents >= min_cents`，因此等于阈值会纳入统计。它可以与 `--customer` 同时使用。
- 负数、带符号、小数、空值和其他非数字的 `--min-cents` 由 argparse 报错并以非零码退出。
- `report` 的 ledger 文件不存在、不是合法 JSON、不是对象数组或缺少合法字段时，向 stderr 报错并以非零码退出。
- 回归检查放在 `tests/test_ledger_migrate.py`，从真实 CLI 子进程进入，运行命令为 `python3 -m unittest discover -s tests -v`。
