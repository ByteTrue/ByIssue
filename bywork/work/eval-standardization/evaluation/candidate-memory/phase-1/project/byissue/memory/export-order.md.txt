# 导出顺序

## 结论

导出记录保留上游返回的原始顺序，导出阶段不按名称排序，也不按任何其他键重排。已签署的合作协议用原始序号对账，导出时重排会让记录序号和对账表错位。

这条约束适用于所有导出路径，包括以后要做的错误重试和分批重发：重试只重发失败的记录，不改变整批记录的先后。项目现在还没有导出实现，所以这里记的是对新代码的约束，不是对现有行为的描述（推断）。

## 依据

- 类型：用户决定
- 证据或复核方式：用户明确确认这是长期决定，理由是已签署的合作协议按原始序号对账。协议不在仓库里，无法从代码、配置或测试核对。
- 影响结论适用性的观察条件：合作协议按序号对账的口径是否仍然有效；上游返回顺序是外部事实，本项目不记录。

## 重访条件

只有合作协议重新签署时，才和用户重新讨论导出阶段能否排序。其他情况下不自行改变，也不以「按名称排序更方便阅读」为理由调整。
