# 错误重试

## 目标与边界

用户下一轮要做的是错误重试功能。本轮没有开始实现，也没有定下重试的触发条件、失败分类和终止方式。

边界：不改变导出顺序（见 `memory/export-order.md`）。本轮不改代码和配置。

## 已定方案与约束

用户已确认的现状事实，读自 `config.json`：

- 重试次数上限 3（`retry_limit`）
- 每批数量 100（`batch_size`）

这两项是配置文件里的当前值，不是长期决定；改动它们不需要走记忆更新。

仍开放的问题：

1. 哪些失败要重试，哪些直接失败退出。
2. 重试用完 3 次之后怎么处理：整批失败、记失败清单，还是继续下一批。
3. 重试是否要加退避等待，还是立即重发。
4. 重试时已经成功的记录是否重发。
