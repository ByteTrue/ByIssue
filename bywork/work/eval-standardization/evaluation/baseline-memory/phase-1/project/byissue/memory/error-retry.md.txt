# 错误重试

## 结论

错误重试功能放到下一轮做。本轮只整理记录，不改代码、不改配置，也不把重试当作已完成的能力。

重试参数以项目根目录的 `config.json` 为准，当前是每批 100 条、失败最多重试 3 次。本记录不复制具体数值，避免配置改了而这里留着旧数字。

到现在为止没有运行过任何业务测试，重试行为没有任何通过证据。需要判断重试是否按预期工作时，按未验证处理。

## 依据

- 类型：用户决定。
- 证据或复核方式：读 `config.json` 确认参数；跑一次真实的批量失败场景，看重试次数和每批条数是否与配置一致。
- 观察条件、版本或环境：结论来自用户在本轮的口头说明，没有代码或日志佐证。

## 重访条件

开始实现重试功能时更新本记录，并把它转成 `byissue/work/` 下的当前工作，写入行为证明契约。配置里的重试次数或每批数量变化时，只更新 `config.json`，本记录仍然有效。
