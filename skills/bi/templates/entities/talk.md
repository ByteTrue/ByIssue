# [主题] talk

> **写法：** 按当时讨论推进的顺序写，每一节 = 一轮推进或一次关键纠正，节标题用议题语言。  
> **自检（出现过的都要落到文中某处，没出现过的整项删除）：** 开场意图 · 关键纠正与最终以何为准 · 已确认决策/约束 · 术语 · 影响与取舍 · 候选质量 · UI 草图 · 仍开放项 · 出口与暂不纳入。  
> 禁止：为套模板打乱讨论顺序、用空标题凑节、把未确认内容写成已确认。

一节的形状大致是：用户当时怎么说 / 要先弄清什么 → 查到什么 → **已确认：…** / **仍开放：…**。极短的 talk 可以只有几段连续叙述。结尾留「出口」：已执行或建议的下一步、暂不纳入什么。
